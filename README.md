🛒 Ghar Ka Saman
A Simple & Smart Grocery List Android App

Ghar Ka Saman is an Android application designed to help users organize their daily grocery shopping in a simple and convenient way. The goal is to make grocery list management easier by allowing users to search for items, organize their shopping lists, and track purchased groceries.

✨ Features
Current Development
Clean and simple user interface
Grocery-themed color palette
Search bar UI
Built with Kotlin and Jetpack Compose
Planned Features
Add grocery items to a shopping list
Manage item quantities
Mark items as purchased
Separate purchased and pending items
Search and filter grocery items
Offline-first functionality
Persistent local storage
🛠️ Tech Stack
Language: Kotlin
UI Framework: Jetpack Compose
UI Components: Material 3
IDE: Android Studio
Version Control: Git & GitHub
🎨 Design

🚀 Getting Started
Prerequisites
Android Studio
Android SDK compatible with the project configuration
Git installed on your computer
Installation
Clone the repository:

git clone https://github.com/YOUR_USERNAME/GharKaSamanApp.git
Open the project in Android Studio.

Allow Gradle to sync and download the required dependencies.

Connect an Android device or start an emulator.

Click Run ▶️ to build and launch the application.

Replace YOUR_USERNAME with your GitHub username.
